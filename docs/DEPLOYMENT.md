# Deployment Guide

## Render Blueprint

`render.yaml` defines:

- Web service: `ai-form-builder-web`.
- MySQL 8 private service: `ai-form-builder-mysql`, using Render's Docker image flow and a persistent disk.
- Queue worker: `ai-form-builder-worker`.
- Persistent disk for public uploads.

## Build And Start

The Dockerfile performs:

```bash
composer install --no-dev --optimize-autoloader
npm ci
npm run build
docker-php-ext-install pdo_mysql zip gd
```

Web start command:

```bash
php artisan migrate --force --seed && php artisan storage:link || true && apache2-foreground
```

Worker start command:

```bash
php artisan queue:work --queue=ai,imports,webhooks,default --sleep=3 --tries=3 --timeout=120
```

## Required Environment Variables

Set these in Render:

- `APP_KEY`: generated by Render blueprint.
- `APP_URL`: deployed web URL.
- `DB_HOST`: wired from the MySQL private service host.
- `DB_PORT=3306`, `DB_DATABASE=form_builder`, `DB_USERNAME=form_builder`.
- `DB_PASSWORD`: must match `MYSQL_PASSWORD` on `ai-form-builder-mysql`.
- `MYSQL_ROOT_PASSWORD` and `MYSQL_PASSWORD`: provide during Blueprint creation.
- `QUEUE_CONNECTION=database`.
- `CACHE_STORE=database` or Redis if provisioned.
- `FILESYSTEM_DISK=public`.
- `OPENAI_API_KEY`: optional but recommended.

Render notes: Render Blueprints define non-Postgres services under `services`, and Render's MySQL template runs MySQL 8 as a private Docker service with a persistent disk. The password values are marked `sync: false`, so enter the same database password for `MYSQL_PASSWORD`, web `DB_PASSWORD`, and worker `DB_PASSWORD`.

## Post Deploy

1. Open `/login`.
2. Use `demo@example.com` / `password`.
3. Start the worker service.
4. Create or publish a form.
5. Test `/f/{token}` and CSV export.
